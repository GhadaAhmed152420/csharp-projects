# Student Management System

A console application built with C# to manage student records.

## Features

- Add Student
- View All Students
- View Student By ID
- Update Student
- Delete Student
- Search Students By Name
- Search Students By Department
- Sort Students By Name
- Sort Students By Age

## Technologies

- C#
- Object-Oriented Programming (OOP)
- Collections (`List<T>`)
- LINQ

## Project Purpose

This project was built to practice C# fundamentals, OOP, collections, and LINQ through a simple console-based application.
